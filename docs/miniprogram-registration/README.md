# 小程序注册资料

微信公众平台“填写小程序信息”一页要填 4 项。下面每项都给出可以直接复制的内容。

**核心结论：** 名称用 **随手译记**，简称同名称，头像上传 `avatar-144.png`，介绍复制标准版。名称全平台唯一，提交时提示重名就按顺序换备选名，头像不用改。

| 文件 | 用途 |
|---|---|
| `avatar-144.png` | 上传用头像，144×144 PNG，6 KB |
| `avatar-1024.png` | 高清版，以后做分享图、小程序码中心图时用 |
| `avatar.svg` | 头像源文件 |
| `render-avatar.sh` | 修改 `avatar.svg` 后重新导出两张 PNG（需要 Chrome 和 ImageMagick） |

## 1. 小程序名称

规则：4–30 个字符，一个汉字算 2 个字符；全平台不能重名。

```
随手译记
```

8 个字符。“随手”指打开就能输入，“译记”指翻译后记下来复习，对应 M3、M4 的每日材料和复习卡。

提示重名时，按下表顺序换：

| 顺序 | 名称 | 字符数 | 说明 |
|---|---|---|---|
| 1 | 随手译记 | 8 | 推荐 |
| 2 | 每日译记 | 8 | 强调每天复习 |
| 3 | 译记英语 | 8 | 更直白，但听起来偏学习类 |
| 4 | 一框译 | 6 | 强调只有一个输入框 |
| 5 | 随手译 | 6 | 只讲翻译，不讲复习 |
| 6 | 译刻 | 4 | 最短，重名的可能性最大 |

避开这些词：“官方”“微信”这类词，别人的品牌名，以及“公司”这类暗示企业主体的词（这是个人主体）。

## 2. 小程序简称

规则：4–10 个字符，只能从名称里按原顺序挑字，显示在任务栏。

```
随手译记
```

名称本身是 8 个字符，没超 10 个，简称直接用全名。换成备选名时也一样：上表的名称都不超过 10 个字符，可以原样作简称。

## 3. 小程序头像

上传 `avatar-144.png`。

- **规格：** PNG，144×144，6 KB，符合表单要求（png 格式、不超过 2 MB、建议 144×144）。
- **内容：** 靛蓝底色上一个白色宋体“译”，右下角一条短横，像终端里闪烁的光标，表示这个工具最早是命令行工具（t-cli）。
- **配色：** 底色和字色就是小程序界面里的强调色和背景色（`apps/miniprogram/miniprogram/app.wxss`），打开后的界面和图标是同一套颜色。
- **显示效果：** 平台会同时把头像显示成圆角方形和圆形。图形全部放在中间的圆形区域里，裁成圆形也不会切到字。缩到 48×48 时仍然清楚。
- **合规：** 只有一个汉字和一条横线，不涉及政治敏感或色情内容。

## 4. 小程序介绍

上限 120。先粘贴标准版：

```
输入中文，译成地道的英文；输入英文、日文、韩文等外语，译成中文。查单个英文单词时附美式音标，可朗读发音。英文纠错会标出改动处，并给出更地道的说法。每次查询自动保存，方便日后复习。
```

标准版共 89 个字。如果计数器显示超过 120（说明一个汉字按 2 个字符计），改用精简版，它共 43 个字，两种算法都不会超：

```
中文译英文，外语译中文；单词附美式音标，可朗读。英文纠错标出改动，并给出更地道的说法。
```

两版介绍都避开了下面这些写法：

- 没有“AI”“智能生成”这类字眼。生成式 AI 服务在正式发布时可能需要额外资质（设计文档 V5，待核实），介绍里不主动写。
- 没有“最”“第一”这类绝对化用语。
- 只写已经做好的功能。复习功能还没做，只写“方便日后复习”。

## 服务器域名怎么填

位置：开发管理 → 开发设置 → 服务器域名。小程序的所有网络请求都走 `wx.request`：普通接口、流式翻译、朗读音频都是。所以只填 request 一栏，另外两栏可选。

| 栏目 | 填写 | 说明 |
|---|---|---|
| request 合法域名 | `https://tcli.guangqingai.top` | 必填 |
| socket 合法域名 | 留空 | 没有用 WebSocket |
| uploadFile 合法域名 | 留空 | 没有上传文件 |
| downloadFile 合法域名 | 留空 | 朗读音频用 `wx.request` 取回，没有用 `wx.downloadFile` |
| udp / tcp 合法域名 | 留空 | 没有用 |
| DNS 预解析域名 | `tcli.guangqingai.top` | 可选，不带 `https://` |
| 预连接域名 | `https://tcli.guangqingai.top` | 可选。它必须同时出现在 request 和 DNS 预解析两栏里，所以只填预解析时这一栏可以不填 |

- 不要写端口和路径，不能写 IP 或 `localhost`。
- 语音输入走“微信同声传译”插件。插件的网络请求不受这里的列表限制，不用另外填域名。
- 只配不用的域名没有好处，也是多余的暴露面，所以其余栏都留空。
- 本机调试不受这个列表限制：开发者工具 → 详情 → 本地设置 → 勾选“不校验合法域名”。
- 待确认：
  - 保存时平台可能检查域名的备案和 HTTPS 证书。如果因为 `tcli` 还没有 DNS 记录或证书而保存失败，等 DNS 和证书就绪后再填。
  - 这个列表每月能改的次数有限，一次填对，不要反复改。
